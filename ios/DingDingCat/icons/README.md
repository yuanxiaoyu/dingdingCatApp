# iOS App Icons

请将以下尺寸的图标文件放置在此文件夹中：

## iPhone 图标尺寸要求：

- **icon-20@2x.png** - 40x40px (iPhone Notification iOS 7-14)
- **icon-20@3x.png** - 60x60px (iPhone Notification iOS 7-14)
- **icon-29@2x.png** - 58x58px (iPhone Settings iOS 7-14)
- **icon-29@3x.png** - 87x87px (iPhone Settings iOS 7-14)
- **icon-40@2x.png** - 80x80px (iPhone Spotlight iOS 7-14)
- **icon-40@3x.png** - 120x120px (iPhone Spotlight iOS 7-14)
- **icon-60@2x.png** - 120x120px (iPhone App iOS 7-14)
- **icon-60@3x.png** - 180x180px (iPhone App iOS 7-14)
- **icon-1024.png** - 1024x1024px (App Store)

## 图标要求：
- 格式：PNG
- 颜色空间：sRGB
- 不要包含透明度
- 不要包含圆角（iOS会自动添加）
- 高质量，无压缩伪影

将图标文件按照上述命名放置在此文件夹中，然后运行配置脚本。
